# 全功能测试用例文档

## 1. LLM 模块测试

### 用例 1.1 基础对话
- 前置条件：DASHSCOPE_API_KEY 已配置
- 测试步骤：调用 DashScopeLLMClient.chat("你好")
- 预期结果：返回正常的中文回复
- 验证点：Token 用量统计正确

### 用例 1.2 多模型切换
- 前置条件：同上
- 测试步骤：分别使用 qwen-turbo / qwen-plus / qwen-max 发送相同问题
- 预期结果：三个模型均返回合理回复，qwen-max 回复更详细

### 用例 1.3 异常处理 - 无效 API Key
- 测试步骤：使用错误的 API Key 调用 chat
- 预期结果：返回友好的错误提示，不抛出未捕获异常

## 2. RAG 知识库模块测试

### 用例 2.1 本地 Embedding 加载
- 前置条件：首次运行或模型已下载
- 测试步骤：初始化 LocalEmbeddingClient
- 预期结果：模型加载成功，无 API 调用

### 用例 2.2 文档入库
- 前置条件：ChromaDB 目录可写
- 测试步骤：上传 TXT 文件并调用 KnowledgeBase.add_document
- 预期结果：文档解析成功，向量入库，返回 chunk 数量

### 用例 2.3 知识检索
- 前置条件：知识库中已有文档
- 测试步骤：使用关键词检索知识库
- 预期结果：返回 Top-5 相关片段，相似度 > 0.45

## 4. 智能对话分析测试

### 用例 4.1 简单取数
- 用户输入："上个月的销售额是多少？"
- 预期结果：Agent 正确识别意图，生成 SQL，查询数据并返回结果

### 用例 4.2 对比分析
- 用户输入："本月和上月的利润对比"
- 预期结果：自动计算同比/环比，生成对比图表

### 用例 4.3 异常诊断
- 用户输入："为什么本周的订单量下降了？"
- 预期结果：调用异常检测工具，分析各维度变化

### 用例 4.4 趋势预测
- 用户输入："预测下个月的用户增长趋势"
- 预期结果：调用 Statsmodels 进行时序预测
